# Taskoria Go Backend

Учебная Go-версия backend Taskoria. Она переписывается вертикальными срезами: один работающий HTTP-сценарий за раз.

## Правило работы

Код пишет автор проекта. Codex объясняет текущий этап, даёт небольшую задачу и подсказки, затем делает code review и помогает исправить ошибки.

## Текущий этап

Этап 1: минимальный HTTP-сервер и `GET /health`.

Условия и критерии находятся в `TASK_01_HEALTH.md`.

## Будущая структура

- `cmd/api` — запуск приложения и сборка зависимостей;
- `internal/httpapi` — HTTP routing, handlers и HTTP-тесты;
- остальные пакеты будут добавляться только тогда, когда появится соответствующая задача.

Пустые слои заранее не создаются.
